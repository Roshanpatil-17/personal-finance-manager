# 💰 Personal Finance Manager

A simple and user-friendly **Personal Finance Manager** application that helps users track their income, expenses, and overall financial health. The application provides an organized dashboard to manage daily transactions and monitor spending habits.

---

## 📌 Features

- ➕ Add Income
- ➖ Add Expenses
- 📊 Dashboard with financial summary
- 💵 Calculate Total Balance
- 📅 Transaction History
- 🗂️ Categorize Income & Expenses
- ✏️ Edit Existing Transactions
- ❌ Delete Transactions
- 🔍 Search and Filter Transactions
- 📈 Visualize Spending (Charts/Graphs if implemented)

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/Roshanpatil-17/personal-finance-manager.git
```

### Navigate to the Project

```bash
cd personal-finance-manager
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000
```
